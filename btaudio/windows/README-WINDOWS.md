# Windows sender documentation

See the repository's [Windows sender guide](../../README-WINDOWS.md) for setup,
usage, build outputs, and integration-test instructions.

Sources and local check entry points are in this directory:

- `bt-audio-send.ps1` / `bt-audio-send.bat` — PowerShell sender.
- `gui/` — WinForms sender source.
- `cscheck.sh` / `pscheck.sh` — C# compile and PowerShell/wire-protocol tests.
